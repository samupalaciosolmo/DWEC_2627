Ejercicio 1. Variables y typeof

Declaración de seis variables de tipos distintos y comprobación de su tipo con typeof.

Código ejecutado:
const numero = 25;
const texto = "Hola";
const esVerdad = true;
const nada = null;
let sinDefinir;
const numeroGrande = 100n;
Resultados (Espero / Sale):
Variable Valor Tipo Esperado Tipo Real (Sale)
numero 25 number number
texto "Hola" string string
esVerdad true boolean boolean
nada null null object
sinDefinir undefined undefined undefined
numeroGrande 100n bigint bigint

Explicación de null: typeof null devuelve "object" por un error histórico mantenido desde las primeras versiones de JavaScript para evitar romper webs antiguas.

Ejercicio 2. Conversiones explícitas

Conversiones explícitas utilizando Number(), String() y Boolean().

Código ejecutado:
String(123);
Number("123");
Number("12abc");
Number("");
Number(true);
Boolean(0);
Boolean("texto");
Boolean("");
Resultados (Conversión / Espero / Sale):
Conversión Resultado Esperado Resultado Real (Sale) Estado
String(123) "123" "123" Acierto
Number("123") 123 123 Acierto
Number("12abc") NaN NaN Acierto
Number("") NaN 0 Fallo de predicción
Number(true) 1 1 Acierto
Boolean(0) false false Acierto
Boolean("texto") true true Acierto
Boolean("") false false Acierto

Ejercicio 3. Coerción y comparaciones

Pruebas de coerción implícita de tipos y comparaciones con == vs ===.

Resultados de Expresiones:
Expresión Espero Sale
"5" - 2 3 3
"5" + 2 "52" "52"
"5" * "2" 10 10
true + 1 2 2
5 == "5" true true
5 === "5" false false
0 == false true true
0 === false false false
null == undefined true true
null === undefined false false

Regla de coerción: Cuando usamos el operador + y uno de los operandos es una cadena de texto, la cadena tiene prioridad y concatena todo como texto. En el resto de operaciones matemáticas (como -, *, /), los números mandan e intentan convertir los textos en números.

Ejercicio 4. Tu ficha con plantillas de cadena

Construcción de mensajes usando plantillas de cadena (backticks) y concatenación tradicional con +.

Error producido al reasignar una constante:
Uncaught TypeError: Assignment to constant variable.

Explicación: Este error aparece cuando intentamos asignar un nuevo valor a una variable declarada con const. Las variables declaradas con const son de solo lectura y no se pueden modificar una vez creadas.
